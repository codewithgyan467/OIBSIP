## Overview
This task is a comprehensive research report analyzing four fundamental network security threats:
1. **Denial of Service (DoS) and Distributed Denial of Service (DDoS)**
2. **Man-in-the-Middle (MitM) Attacks**
3. **IP Address Spoofing**
4. **DNS Cache Poisoning / DNS Spoofing**

The complete technical report includes:
- Attack mechanisms and execution flow diagrams
- Real-world case studies (2016 Dyn Mirai DDoS, 2011 DigiNotar CA breach, 2018 GitHub Memcached attack, 2015 Malaysia Airlines DNS hijacking)
- Organizational impact analysis
- Multi-layer defense mitigations (BCP 38, DNSSEC, TLS 1.3, HSTS, uRPF)
- Comprehensive threat comparison matrix
